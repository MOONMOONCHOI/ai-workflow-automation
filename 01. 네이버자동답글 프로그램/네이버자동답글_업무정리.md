업무명: 네이버 블로그 댓글 자동 답글 프로그램 (네이버자동답글 v1.5)
도구: Python, Playwright(크롬 자동화), SQLite(중복 방지 DB), Tkinter 기반 GUI, Windows 작업 스케줄러(매일 자동 실행)
효용:
- 고용주(대표): 직원이 블로그 글마다 일일이 달던 반복 댓글 응대 시간을 없애고, 매일 9시·13시·17시 자동 실행으로 별도 인력 투입 없이 운영 — 응대 인건비·시간 절감
- 학습자(실무자): "같은 문구를 손으로 계속 달아야 하는" 단순 반복 업무에서 벗어남. 놓친 댓글이 없는지 신경 쓰던 부담과 반복 피로가 사라짐

---

### [작업 내용 & 핵심 결과물]
- 어떤 상황인가요?: 직원이 블로그 본문에 달리는 댓글마다 동일한 안내 문구를 매번 직접 찾아서 답글로 달아야 했음. 글이 쌓일수록 확인·응대 시간이 늘어나고, 이미 답한 댓글을 또 확인하는 비효율도 반복됨.
- 핵심 입력 조건: 블로그 ID, 본인 닉네임(자기 댓글·자동 답글에는 재응답 안 하도록 제외 대상 지정), 한 번에 순회할 글 수, 최대 답글 수, 답글 사이 대기 시간(8초 이상 권장), 등록할 답글 문구, 비밀댓글 등록 여부
- 최종 해결책: Playwright로 크롬을 띄워 네이버에 로그인(최초 1회) → 대상 블로그 포스팅 URL을 자동 수집해 SQLite에 누적 → 각 글의 댓글을 순회하며 미답변 댓글에만 고정 템플릿 답글 등록 → 처리한 댓글 ID를 DB에 기록해 중복 응답 방지. `점검 실행`(dry-run)으로 실제 등록 없이 대상 댓글만 먼저 확인 가능하고, `매일 자동 실행 등록`으로 화면 방해 없이 백그라운드 자동 운영.

### [학습자용 실무 팁 & 주의점]
- 흔히 하는 실수: 답글 사이 대기 시간을 8초 미만으로 줄여 스팸으로 걸리는 경우, `설치하기.bat`을 먼저 실행하지 않고 바로 `실행하기.bat`을 눌러 오류가 나는 경우, 로그인 세션이 저장된 `naver_profile` 폴더를 함부로 지워 재로그인을 반복하게 되는 경우
- 바로 써먹는 꿀팁: 실제 등록 전엔 반드시 `점검 실행`으로 로그에서 어떤 댓글이 대상으로 잡히는지 먼저 확인할 것. 비밀댓글 옵션을 켜두면 체크박스가 정상 반영 안 됐을 때 자동으로 등록을 중단하고 다음 실행에서 재시도하는 안전장치가 있으니, 실행 로그의 중단 사유를 확인하는 습관을 들이면 오작동을 바로 잡아낼 수 있음.

### 그 외에 작업 진행에 대한 프로세스 내용
- 완성된 배포본(`네이버자동답글_v1.5.zip`)만 `0.업무자동화 자료실\02_완료` 폴더에 남아 있고, 설계 배경이나 프롬프트 대화 이력 같은 제작 기록은 따로 저장돼 있지 않음 — 그래서 이번 정리는 zip 압축 해제 후 소스 코드(`main.py`, `gui.py`)와 `사용설명서.txt`를 직접 확인해 역으로 재구성한 내용임.
- 메인 화면 스크린샷은 이번 정리에 포함하지 못함. 이 PC에는 프로그램이 설치·실행된 상태가 아니라 zip 원본만 있고, 캡처를 위해 의존성 설치(`설치하기.bat`)와 GUI 실행까지 진행할지 확인한 결과 "설치·실행 없이 문서만 제공"으로 결정됨. 실제 사용 중인 PC(예: 담당 직원 PC)에서 캡처한 이미지를 확보하면 이 문서에 추가하면 됨.
